# 디자인과 폴드 화면 대응

## 사용한 디자인 기준

이번 개편은 첨부된 `daily-briefing.html`의 단순한 읽기 흐름을 기준으로 합니다. 날짜를 강조한 보고서 머리글, 밑줄로 현재 분야를 표시하는 메뉴, 17px 요약 본문을 적용했습니다. 기존의 어두운 바탕, 연한 파랑과 오렌지 포인트, 상단 고정 헤더, 하단 탐색 메뉴, 갱신 상태는 유지합니다. 좁은 화면에서는 구분선으로 기사를 나누고 넓은 화면에서는 낮은 대비의 카드 면을 사용합니다.

첨부 파일의 샘플 기사나 날짜를 실제 뉴스로 넣지 않습니다. 기사가 없으면 빈 상태를 표시합니다. 최근 5일 보고서 목록, HOT 10, 최신, 기존 분야, 검색, 브라우저 저장, 공유, 읽기 진행률과 갱신 현황을 유지합니다. 기존 주소의 분야 해시와 기능 연결도 보존합니다.

외부 Tailwind 실행 CDN과 Google Fonts 요청을 제거했습니다. 배포 화면은 로컬 CSS·JavaScript·SVG 아이콘만 사용합니다. 시스템에 설치된 한글 폰트를 사용하므로 OS별 글꼴은 조금 다를 수 있습니다.

## 기존 반응형에서 유지한 부분

기존 첨부 디자인에서 가져온 내부 화면 조건은 그대로 유지합니다.

```css
@media (min-width: 600px) and (max-aspect-ratio: 1.3/1)
```

이 조건과 최대 너비 860px의 의도를 유지했습니다. 해당 조건에서 목록과 보고서 카드가 2열이 됩니다. 열은 `minmax(0, 1fr)`로 구성하고 긴 영문 저장소 이름과 제목이 열 너비를 밀어내지 않도록 줄바꿈을 허용했습니다.

원본의 `min-aspect-ratio: 20/10`은 너비/높이가 2 이상인 **가로로 긴 화면**에 적용됩니다. 좁고 긴 커버 화면 조건이 아니므로 이를 그대로 커버 화면 최적화라고 보지 않았습니다. 기존 가로형 조건은 남기되, 좁은 화면에는 별도로 `max-width: 599px` 조건을 적용했습니다.

| 영역 | 구성 |
|---|---|
| 좁은 화면, 599px 이하 | 구분선 중심의 1열 목록, 좁은 여백, 가로로 스크롤되는 분야 메뉴 |
| 내부 화면 조건, 600px 이상 & 비율 1.3 이하 | 2열 카드, 최대 860px, 너비에 반응하는 여백 |
| 넓은 데스크톱, 900px 이상 | 2열 카드, 넓은 읽기 공간 |
| 회전·분할 화면 | 기기 이름이 아닌 실제 viewport에 맞춰 다시 배치 |

여기의 px는 **물리 해상도가 아니라 CSS viewport 단위**입니다. 갤럭시 폴드 8 울트라의 물리 픽셀 수를 임의로 정해서 고정하지 않았습니다. 브라우저 확대, 글꼴 크기, 화면 확대, 분할 화면 설정에 따라서 같은 기기에서도 사용 가능한 CSS 너비가 달라집니다.

## 모바일 사용성

화면 확대를 막던 `maximum-scale=1`, `user-scalable=no`는 제거했습니다. `viewport-fit=cover`와 상하단 safe-area는 유지합니다. 헤더와 하단 메뉴가 본문 끝을 가리지 않도록 여백을 확보했습니다. 버튼은 기본 44px 영역을 제공하며 키보드 포커스를 표시합니다. 움직임 감소 설정도 존중합니다.

카드 제목과 요약은 바로 읽을 수 있습니다. 수집 기준, 분야와 HOT 선정 이유, CVE 평가 근거는 필요할 때 펼치는 상세 영역에 둡니다. 검색은 발생 배경과 접힌 상세도 검사합니다. 검색어가 들어 있는 상세는 펼치고 검색어를 지우면 기존 펼침 상태로 돌아갑니다. CVE는 최대 40건을 게시하며 기존의 20건씩 더 보기 동작을 유지합니다.

새 요약의 발생 배경은 짧은 별도 문단으로 표시합니다. 원문 근거가 없어 빈 값이면 원문에 배경이 없다는 안내를 보여 줍니다. 배경 필드가 없는 과거 요약에서는 해당 영역을 생략합니다. 제목, 원문 링크와 검색에 긴 문자열이 들어가도 화면 너비를 밀어내지 않도록 처리합니다.

수집원 상태는 정상, 오류, 수집 제외를 구분합니다. 제외는 회색과 사유 문구를 함께 사용하며 오류가 해결된 것처럼 표시하지 않습니다. 접기와 링크는 HTML 기본 동작을 사용해 JavaScript 없이도 보고서를 읽을 수 있습니다.

## 실기기에서 확인할 항목

기기를 접고 펼쳤을 때 카드 열 수, 회전 시 가로 넘침, 상단 상태 표시줄과 하단 제스처 영역 간섭, 글자 크기를 키웠을 때 메뉴·버튼·원문 링크, 긴 GitHub 저장소 이름, 보고서 검색 후 빈 상태를 확인하세요.

기존 디자인의 자동 검증은 가상 viewport에서 수행한 기록입니다. 이 기록이 이번 개편의 검증 결과를 대신하지는 않습니다. 갤럭시 폴드 8 울트라 실기기로 접기, 펼치기와 힌지 센서 동작까지 검증한 것은 아닙니다.
